# Drive Menu — CarPlay shortcut for Ryan

**Install on iPhone:** open `Drive Menu.shortcut` from this folder (Files or Safari download) → Add Shortcut.
Then, once: Shortcuts app → Automation → + → CarPlay → Connects → Run Immediately → run **Drive Menu**.

**Menu branches**
- Go Home / Go to Work — driving directions to "Home" / "Work" (resolved by Maps from your contacts card; if Maps can't resolve one, edit that branch's destination to the address).
- Spotify — opens Spotify search for **Happy Mix** (your personalized mix; first result is yours).
- Podcasts — opens Apple Podcasts.
- JARVIS — opens the boot animation at https://tryyentaai.github.io/other/jarvis/ and the track **"Iron Man" — Black Sabbath** (spotify track 4svkPL62HbvyFgf0nHFXAF; verified — no Iron Maiden version exists).

**Known caveat:** this .shortcut file is unsigned (authored by Don off-device). Modern iOS prefers signed shortcut files; if your phone refuses the import, the fallback is signing it on your Mac or a 20-second in-app rebuild from the spec in `carplay-menu-build-sheet.md`.
